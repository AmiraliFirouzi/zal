## معرفی زال
**زال** پلتفرمی است متن‌باز و کامیونیتی‌محور برای گردآوری، معرفی و دسترسی آسان به بهترین مدل‌های زبانی و دیتاست‌های زبان فارسی. هدف ما ایجاد یک دایرکتوری متمرکز برای کمک به پژوهشگران، توسعه‌دهندگان و علاقه‌مندان به هوش مصنوعی در توسعه‌ی برنامه‌های مبتنی بر زبان فارسی است.

## ویژگی‌ها
- 🌟 **لیست جامع:** دسترسی به جدیدترین و برترین مدل‌های زبانی و دیتاست‌های فارسی.
- 🔍 **جستجو و فیلتر:** جستجوی آسان و فیلتر کردن بر اساس مدل، دیتاست و محبوبیت.
- ⭐ **علاقه‌مندی‌ها:** امکان ذخیره مدل‌ها و دیتاست‌های مورد علاقه در مرورگر شما.
- 🚀 **متن‌باز و مشارکتی:** هر کسی می‌تواند مدل یا دیتاست خود را ثبت کند تا به لیست اضافه شود.
- ⚡ **سرعت بالا و طراحی زیبا:** ساخته‌شده با Next.js 16، Tailwind CSS و الهام‌گرفته از هنر و فرهنگ ایرانی.

## نحوه‌ی ثبت مدل یا دیتاست
برای ثبت مدل یا دیتاست جدید خود در زال، نیازی به ایجاد دستی Issue نیست!
1. به وب‌سایت [زال](https://github.com/AmiraliFirouzi/zal) مراجعه کنید (لینک را پس از استقرار به‌روز کنید).
2. روی دکمه‌ی **«ثبت مدل یا دیتاست»** کلیک کنید.
3. فرم را با اطلاعات مدل یا دیتاست خود پر کنید.
4. با ارسال فرم، یک Issue به‌صورت خودکار در این مخزن گیت‌هاب ایجاد می‌شود.
5. پس از بررسی توسط تیم، مدل شما به `src/data/items.json` اضافه شده و در سایت نمایش داده خواهد شد.

## راهنمای راه‌اندازی برای توسعه‌دهندگان
اگر می‌خواهید به توسعه‌ی وب‌سایت زال کمک کنید، مراحل زیر را دنبال کنید:

### پیش‌نیازها
- Node.js (نسخه‌ی 18 یا بالاتر)
- npm یا yarn یا pnpm

### نصب و اجرا
1. مخزن را کلون کنید:
   ```bash
   git clone https://github.com/AmiraliFirouzi/zal.git
   cd zal
   ```

2. وابستگی‌ها را نصب کنید:
   ```bash
   npm install
   ```

3. سرور توسعه را اجرا کنید:
   ```bash
   npm run dev
   ```

4. مرورگر خود را باز کرده و به آدرس `http://localhost:3000` بروید.

## ساختار پروژه
- `src/app/`: صفحات اصلی وب‌سایت (Next.js App Router).
- `src/components/zal/`: کامپوننت‌های رابط کاربری، آیکون‌ها و توابع کمکی.
- `src/data/items.json`: پایگاه داده‌ی محلی که لیست مدل‌ها و دیتاست‌ها در آن ذخیره می‌شود.

## استقرار (Deployment)
این پروژه برای استقرار روی **GitHub Pages** پیکربندی شده است. هر بار که کدی در شاخه‌ی `main` پوش (Push) شود، GitHub Actions به‌طور خودکار سایت را بیلد کرده و منتشر می‌کند.
- تنظیمات مربوط به GitHub Pages در `next.config.ts` و فایل‌های Action در `.github/workflows/nextjs.yml` قرار دارند.
- اگر می‌خواهید آن را روی Vercel یا Netlify مستقر کنید، باید تنظیمات `basePath` و `output: "export"` را از `next.config.ts` حذف کنید.
